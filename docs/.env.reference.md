# Odoo MCP Server 环境变量参考 / Environment Variables Reference

## Odoo 连接 / Odoo Connection

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_URL` | ✅ | — | Odoo 服务器地址，必须以 `http://` 或 `https://` 开头 / Odoo server URL, must start with `http://` or `https://` |
| `ODOO_DB` | ❌ | 自动检测 | 数据库名称，不填则从 Odoo 自动检测 / Database name, auto-detected if not set |
| `ODOO_USER` | ❌* | — | 登录用户名（与 `ODOO_PASSWORD` 配对使用）/ Login username (paired with `ODOO_PASSWORD`) |
| `ODOO_PASSWORD` | ❌* | — | 登录密码 / Login password |
| `ODOO_API_KEY` | ❌* | — | API Key 认证（优先于账号密码，在 Odoo 用户设置中生成）/ API key auth (preferred over user/password, generated in Odoo user settings) |

> *`ODOO_API_KEY` 和 `ODOO_USER`+`ODOO_PASSWORD` 二选一

---

## 语言与模式 / Locale & Mode

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_LOCALE` | ❌ | `zh_CN` | 语言区域设置，通过 RPC context 中的 `lang` 传递给 Odoo，影响字段标签、选项值、记录名称等的翻译。设为空字符串可禁用 / Locale injected via RPC context `lang`, affects field labels, selection values, record names. Set to empty string to disable |
| `ODOO_YOLO` | ❌ | `off` | YOLO 模式：`off`（关闭）、`read`（只读直连）、`true`（完整 CRUD 直连）。绕过 MCP 插件，直接连接标准 XML-RPC / YOLO mode: `off`, `read` (read-only direct), `true` (full CRUD direct). Bypasses MCP plugin |

## 日志 / Logging

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_MCP_LOG_LEVEL` | ❌ | `INFO` | 日志级别：`DEBUG`、`INFO`、`WARNING`、`ERROR`、`CRITICAL` / Log level |

---

## 传输方式 / Transport

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_MCP_TRANSPORT` | ❌ | `stdio` | MCP 传输协议：`stdio`（标准输入输出）、`sse`（Server-Sent Events）、`streamable-http`（HTTP 流式） / MCP transport protocol |
| `ODOO_MCP_HOST` | ❌ | `localhost` | HTTP 传输模式下的监听地址 / Listen host for HTTP transport |
| `ODOO_MCP_PORT` | ❌ | `8000` | HTTP 传输模式下的监听端口 / Listen port for HTTP transport |

> HTTP 传输模式（`sse` / `streamable-http`）必须显式设置 `HOST` 和 `PORT`

## 安全 / Security

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_MCP_HTTP_TOKEN` | ❌* | — | HTTP 传输的 Bearer Token 鉴权令牌。非本地监听时必须设置 / Bearer token for HTTP transport auth. Required for non-localhost |
| `ODOO_MCP_STRICT_SECURITY` | ❌ | `true` | 严格安全模式。开启后非本地监听必须提供 Token / Strict security mode |
| `ODOO_MCP_ALLOWED_HOSTS` | ❌ | — | 允许访问的主机白名单，逗号分隔 / Allowed hosts whitelist, comma-separated |
| `ODOO_MCP_ALLOWED_ORIGINS` | ❌ | — | CORS 允许的来源，逗号分隔 / CORS allowed origins, comma-separated |
| `ODOO_MCP_STATELESS_HTTP` | ❌ | `true` | 无状态 HTTP 模式（每次请求独立认证）/ Stateless HTTP mode (independent auth per request) |

> *严格安全模式下，非 `localhost` 监听时 `HTTP_TOKEN` 必填

---

## 访问控制 / Access Control

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_MCP_READONLY` | ❌ | `true` | 只读模式，禁止所有写操作（create/write/unlink）/ Read-only mode, blocks all write operations |
| `ODOO_MCP_MODEL_ALLOWLIST` | ❌ | 全部允许 | 模型白名单，逗号分隔。设置后只允许访问列出的模型 / Model allowlist, comma-separated |
| `ODOO_MCP_MODEL_BLOCKLIST` | ❌ | 无 | 模型黑名单，逗号分隔。禁止访问列出的模型 / Model blocklist, comma-separated |
| `ODOO_MCP_WRITE_ALLOWLIST` | ❌ | 全部允许 | 写操作白名单，逗号分隔。限制哪些模型允许写入 / Write allowlist, restricts which models can be written |
| `ODOO_MCP_DISABLED_TOOLS` | ❌ | 无 | 禁用的工具列表，逗号分隔。如 `create_record,delete_record` / Disabled tools, comma-separated |

## 性能 / Performance

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_MCP_MAX_WORKERS` | ❌ | `20` | 最大并发工作线程数 / Max concurrent worker threads |
| `ODOO_MCP_DEFAULT_LIMIT` | ❌ | `10` | 搜索默认返回条数 / Default search result limit |
| `ODOO_MCP_MAX_LIMIT` | ❌ | `100` | 搜索最大返回条数（防止大数据量查询）/ Max search result limit |
| `ODOO_MCP_MAX_SMART_FIELDS` | ❌ | `15` | 智能字段选择返回的最大字段数 / Max fields returned by smart field selection |
| `ODOO_MCP_MAX_BULK_SIZE` | ❌ | `100` | 批量操作最大记录数（create/update/delete）/ Max records per bulk operation |

---

## API 版本 / API Version

| 变量 / Variable | 必填 | 默认值 | 说明 / Description |
|---|---|---|---|
| `ODOO_MCP_API_VERSION` | ❌ | `auto` | API 协议版本：`auto`（自动检测）、`xmlrpc`（Odoo 14-18）、`json2`（Odoo 19+）/ API protocol version |

> 通常无需手动设置，连接时会根据 Odoo 版本自动选择

---

## 完整最小配置示例 / Minimal Configuration Example

```env
ODOO_URL=http://localhost:8069
ODOO_DB=my_database
ODOO_USER=admin
ODOO_PASSWORD=admin
```

## 生产环境推荐配置 / Production Recommended

```env
ODOO_URL=https://odoo.example.com
ODOO_DB=production
ODOO_API_KEY=your-api-key-here

ODOO_MCP_TRANSPORT=streamable-http
ODOO_MCP_HOST=0.0.0.0
ODOO_MCP_PORT=8000
ODOO_MCP_HTTP_TOKEN=your-secret-token
ODOO_MCP_STRICT_SECURITY=true
ODOO_MCP_READONLY=true
ODOO_MCP_MAX_WORKERS=20
ODOO_MCP_DEFAULT_LIMIT=10
ODOO_MCP_MAX_LIMIT=200
ODOO_YOLO=off
```
